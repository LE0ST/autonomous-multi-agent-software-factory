## Decisions and closure

This delta preserves previously accepted authority and payload rules, then freezes only the choices the prior adjudication left open:

- **Preserved/frozen:** message-mode local pipe; fixed `ReadFixtureHead`; A2/P10 authority; fresh A3 head read; no cached head; canonical P11 bytes; A3's independently fixed selected case; no A1/M4/M5 operation, case, retry, or expectation authority; P12 is not a head or recovery source.
- **Now selected by O1–O7 and specified here:** BA collector to A2 P14 delivery for post-start facts; one narrow C process-object query ACE; separate P15 selected-case record; fixed little-endian envelope/version/lengths/literals; CSPRNG nonce and one-request connection; active-before-terminal commissioning with fresh P11/P14/P15 lifetimes.
- **Still observations/implementation evidence, not design defaults:** actual G2 SIDs, file IDs, hashes, descriptors, process/pipe facts, collector/broker source integrity, and proof that the proposed ACLs/API behavior work on the commissioned host. The pure codec does not depend on those values.

## M1 and minimum topology delta

O1's boundary is preserved. C receives no service-object, P6, token, pipe-descriptor, debug, memory-read, duplicate-handle, write, or control right. BA/SY collector observations are delivered only in a narrow P14 file under P3, with a fixed schema and read-only C access. E1 remains BA/SY-only.

One additional process-object right is required for race-resistant lifetime binding. `GetNamedPipeServerProcessId` returns a PID, not a process incarnation. If A2 only compares that PID to a static record, a PID reused by a later process could match stale endpoint evidence. Therefore the A3 process DACL must grant the created C SID **only** `PROCESS_QUERY_LIMITED_INFORMATION | SYNCHRONIZE` (`0x00101000`) on that broker process object. A2 opens the exact PID returned by the connected pipe, calls `GetProcessTimes` and `QueryFullProcessImageNameW`, and holds the process handle through the exchange. It does not open the B token. The protected collector supplies actual B TokenUser and the image-file hash. The exact process-object ACE is a reviewed topology delta; if the source cannot install/read back this one ACE without enabling debug privilege, startup stops and the design returns to review. No broader right is implied.

The reason for this narrow exception and its exact row are recorded in [G1_MANIFEST_DELTA_PROPOSAL.md](G1_MANIFEST_DELTA_PROPOSAL.md). Microsoft API access requirements were checked against the official documentation for [GetNamedPipeServerProcessId](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getnamedpipeserverprocessid), [process access rights](https://learn.microsoft.com/en-us/windows/win32/procthread/process-security-and-access-rights), [QueryFullProcessImageNameW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-queryfullprocessimagenamew), [OpenProcessToken](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-openprocesstoken), and [service query rights](https://learn.microsoft.com/en-us/windows/win32/services/service-security-and-access-rights). Those sources support API/access semantics only; they do not prove this host grants the proposed process ACE.
